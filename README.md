# SPA Booking System – Refactored Version (PHP)

This repository contains the **refactored version** of a real-world booking system originally built for a spa and wellness center.  
The core functionality and tech stack remain the same as the original (PHP, JavaScript, MySQL), but the **codebase was reorganized and optimized** to improve readability, structure, and maintainability.

---

## 📌 Purpose

This version represents the **second stage** in a multi-phase technical evolution:

1. ✅ **Legacy version** (2019–2020): original codebase written in raw PHP.
2. 🔧 **Refactored version** (2022): improved version using the same technologies, but with better practices.
3. 🚀 **Modern version** (in progress): complete migration to .NET Core with a RESTful API.

---

## 🏆 Real-World Impact

This system is still in **active use by the client** and continues to generate revenue.  
The refactoring allowed for smoother updates, better scalability, and an easier path toward modernization.
